# Changelog

## 0.1.0

First release.

- `asana-task` skill: seven-phase pipeline from an Asana link to a reviewed, QA'd branch and PR, with the user deciding scope and when to push.
- Per-user repo profiles (draft, import, growth, 60-day trap ageing) stored under `~/.claude/asana-task-data`.
- Machine config with tool detection (`git`, `gh`, `node`, `orca`, `codex`).
- Task briefs and one-shot push grants.
- PreToolUse guard, active only while a brief exists for the current repo and branch: blocks `git add .`/`-A`, pushes without a grant, force-push and `--no-verify`; asks before `gh pr create`/`comment` and Asana comments; warns on commits carrying `[DBG` lines, a lockfile or a forbidden path.
- Agents: `scout` (already fixed? client vs main), `reviewer` (diff against brief), `qa` (PASS/FAIL per criterion).
- Codex export of the skill and a Cursor hooks snippet, generated by `npm run build:export`.
- Fallback rules for when `superpowers` or `ponytail` are not installed.
